# Grounded & Fruitful backend

Production-oriented Firebase Functions v2 backend on Node 22 and strict TypeScript. Domain services own policy; HTTP functions are adapters; Admin SDK repositories own persistence.

## Commands

`npm install`, `npm run lint`, `npm test`, `npm run test:integration`, `npm run build`, `npm run emulators`, and (with emulator variables set) `npm run seed`.

See [architecture](docs/backend-architecture.md), [local setup](docs/local-development.md), and [API](openapi.yaml).
