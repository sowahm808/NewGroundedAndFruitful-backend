# Privacy

Collect only operationally necessary child data. Wellbeing notes, character ratings, observations, grades and reflections are excluded from leaderboards and logs and require purpose-specific authorization. Consent is a replaceable record with guardian, version, timestamp, state and provider verification metadata. Revocation blocks new participation. Disablement, guardian access, retention, export, and deletion workflows must preserve legally/audit-required immutable records while deleting eligible content.
