# Backend architecture

The application is an Express service deployed as a Render container, with schema-validated DTOs, application/domain services, authorization helpers, and Admin SDK repositories. Features remain independently organized under `src`. The current HTTP foundation implements authentication, participant reads, and configured completion awards; character, Bible, and project files currently contain domain helpers rather than complete feature APIs. Additional endpoints must follow the same boundaries. No client value may control identity, role, team, award amount, or approval state.
